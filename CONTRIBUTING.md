## Contributing

Contributions are welcome. To contribute:

1. **[Fork](https://github.com/ubaidslab/Executive-AI-Operations-Assistant/fork) the repository.**

2. **Create a new branch:**
   ```bash
   git checkout -b feature/your-feature-name
   ```

3. **Make your changes.** Before committing, make sure the checks CI runs also pass locally:
   ```bash
   npm run lint
   npm run typecheck
   npm test
   npm run build
   ```

4. **Commit and push:**
   ```bash
   git commit -m "Add: short description of your change"
   git push origin feature/your-feature-name
   ```

5. **Open a [pull request](https://github.com/ubaidslab/Executive-AI-Operations-Assistant/pulls)** describing what changed and why.
